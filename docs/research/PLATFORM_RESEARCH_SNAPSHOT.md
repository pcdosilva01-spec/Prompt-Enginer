## Versions and availability

The documentation pages are living or point to mutable branches, so this report does not attach a guessed client version to them. The local environment has Python 3.12.10. Host executables were not used to assert agent-client versions. The model/version snapshots in the preserved six-volume dossier are separate and dated; they are not platform versions and should be rechecked before a current recommendation.

## Conclusion

The installer supports nine filesystem destinations documented as compatible by their respective host sources, with Roo Code explicitly marked legacy. ChatGPT Web is manual-only. Windsurf/Cascade and Devin Local are excluded from install targets because current evidence did not establish one equivalent, stable skill path for that adapter. A documented path means only that the directory is recognized by that host's documentation; the CLI copies files and cannot establish that an account, editor, or model loads them.
