# Matriz de compatibilidade e evidência de host

**Conferida em 23/11/2026.** “Formato compatível” significa documentação de suporte a uma pasta `SKILL.md`; não significa instalação, execução, garantia de aderência ou equivalência de ferramentas. Codex/ChatGPT, o modelo que a plataforma seleciona e o harness são camadas distintas.

| Host/superfície | Evidência e caminho documentado | Descoberta/ativação e recursos | Ferramentas/permissões | Estado deste pacote e adaptação |
|---|---|---|---|---|
| Agent Skills (formato) | [Spec oficial](https://agentskills.io/specification): pasta com `SKILL.md`, `name`, `description`; recursos opcionais | Carregamento conforme implementação do agente | Execução depende do host | Núcleo produzido conforme spec; sem afirmar compatibilidade absoluta |
| OpenAI Codex / ChatGPT Skills | [OpenAI Build Skills](https://developers.openai.com/codex/skills), [Skills concepts](https://developers.openai.com/plugins/concepts/skills), [API Skills](https://developers.openai.com/api/docs/guides/tools-skills): instruções + recursos; paths atuais `.agents/skills/` no repo, `$HOME/.agents/skills/` user e `/etc/codex/skills/` admin; `agents/openai.yaml` opcional para UI/política | Codex documenta invocação explícita/implícita via descrição; API tem upload/versões e disponibilização no sandbox | Skills não fornecem ferramentas por si; harness controla shell, ferramentas e aprovação | `.codex/skills/` não consta na página atual reaberta; adaptador OpenAI; nenhum upload/instalação feito. Validar descoberta na sessão cliente |
| Claude Code | [Docs Claude Code](https://code.claude.com/docs/en/skills): `.claude/skills/<name>/SKILL.md`, `~/.claude/skills/`; carregamento da pasta, referência sob demanda | `/skill-name` ou chamada contextual; regras de frontmatter adicionais são extensão Claude | `allowed-tools`, invocation controls e ferramentas dependem da configuração | Conteúdo standard; adaptador em `adapters/anthropic.md`; não usa extensões Claude específicas |
| Claude.ai/Cowork/cloud | Mesma doc oficial distingue skills sincronizadas pela conta de skills de máquina local | Skills locais de Claude Code não são automaticamente carregadas em sessões cloud/Cowork; sincronizar/upload pela conta | Varia por sessão cloud | Instalação separada e dependente da conta; requer verificação manual |
| Cursor Editor/CLI/Cloud | [Docs Cursor](https://cursor.com/docs/skills): `.agents/skills/`, `.cursor/skills/`, compatibilidade `.claude/skills/`, `.codex/skills/` | Descoberta automática e `/`; skills locais não passam para Cloud/SSH sem sincronização/publicação documentada | Ferramentas próprias da sessão | Adaptador em `adapters/coding_agents.md`; host não instalado/testado |
| Gemini CLI | [Creating](https://github.com/google-gemini/gemini-cli/blob/main/docs/cli/creating-skills.md), [Using](https://github.com/google-gemini/gemini-cli/blob/main/docs/cli/using-agent-skills.md): `.gemini/skills/`, `.agents/skills/`, pastas globais | `/skills list`, `/skills reload`, ativação com consentimento | Ativação concede leitura de recursos; shell ainda sujeito às permissões do CLI | `adapters/google.md`; adaptar caminho e aguardar consentimento. Não instalado |
| Google Antigravity App/CLI/IDE | [Docs Antigravity](https://antigravity.google/docs/skills): `.agents/skills/`; global `~/.gemini/config/skills/`; paths adicionais variam pela superfície | Auto ativação ou `/nome`; verificar no painel/`/skills` | Ferramentas, consentimentos e carregamento de plugins dependem da superfície | `adapters/google.md`; usar caminho da superfície, não presumir que App e CLI sejam idênticos |
| GitHub Copilot | [Docs skills](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/add-skills): `.github/skills/`, `.agents/skills/`, `.claude/skills/`; pessoal `~/.copilot/skills/`, `~/.agents/skills/` | O suporte depende do app/CLI/cloud agent/review/IDE; CLI tem `copilot skill list` | Docs alertam que pré-aprovar shell remove confirmação; não especificamos `allowed-tools` | Pasta standard; use adapter em `adapters/coding_agents.md`; valide superfície específica |
| Cline | [Docs Cline](https://docs.cline.bot/customization/skills): `.cline/skills/`, `.clinerules/skills/`, `.claude/skills/`; global `~/.cline/skills/` | Painel Skills, auto carregamento e slash commands; recursos em `docs/`, `templates/`, `scripts/` | Habilitação de skill e aprovações de tools permanecem separadas | `adapters/coding_agents.md`; não instalado |
| OpenCode | [Docs OpenCode](https://opencode.ai/docs/skills/): `.opencode/skills/<id>/`; também lê `.agents/skills` e `.claude/skills` conforme precedência documentada | Ferramenta skill carrega instrução quando pertinente | Permissões `permission` do OpenCode controlam execução; arquivos não elevam permissões | `adapters/coding_agents.md`; usar ID/pasta compatíveis |
| Devin Local | [Docs de customizations](https://docs.devin.ai/desktop/devin-local/customizations), obtidas por redirect da antiga URL Windsurf: `.devin/skills/`; `.agents/skills/` e legado `.windsurf/skills/` lidos | Auto ou `/nome`; painel Customize lista carregados | Docs descrevem aprovação antes de MCP, hooks para policy; ferramentas variam | `adapters/coding_agents.md`; registrar explicitamente redirecionamento e mudança de produto |
| Windsurf / Cascade | URL oficial consultada [redireciona para Devin Local](https://docs.windsurf.com/windsurf/cascade/skills); isso não prova equivalência de produto/sessão | Não confirmado nesta rodada para o Cascade legado | Não confirmado | Não declare suporte ativo do antigo Cascade. Adaptar só após verificar a versão e a superfície instalada |
| Roo Code | [Docs oficiais arquivados](https://roocodeinc.github.io/Roo-Code/): encerramento anunciado em 15/05/2026 | Legado; não recomendar instalação nova | Estado histórico; suporte do fork não é inferido | Sem adaptador operacional; migração para Cline/ZooCode exige avaliação separada |
| Aider / harness Markdown genérico | Sem protocolo nativo de Agent Skills verificado nesta matriz | Pode usar conteúdo manual em arquivo de convenções/prompt quando o produto documentar; isso não é skill descoberta automaticamente | Ferramentas seguem o harness | Adaptador genérico documenta injeção controlada; conferir docs/version antes de afirmar localização |

## Fontes primárias verificadas

Os links acima foram abertos ou pesquisados em 23/11/2026. Vários documentos são páginas vivas sem data editorial visível; nesse caso a data editorial é **não indicada**, e a data aqui registrada é somente a consulta. A URL de Windsurf redirecionou para Devin Local, por isso claims de equivalência foram deliberadamente limitados. Consulte `universal-prompt-engineering/references/platforms/platform_adaptation.md` para os detalhes e a política de claims.
