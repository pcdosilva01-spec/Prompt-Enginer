# Evaluation and delivery workflow

1. Confirm the exact approved summary revision is still current. If not, restart approval.
2. Evaluate prompt text against the weighted rubric. Give criterion scores/reasons for material decisions; compute the weighted total correctly.
3. Review completeness, clarity, consistency, feasibility, model/platform fit, security, and testability. Repair actionable defects and repeat the rubric.
4. If a model output has not actually been tested, do not infer success. Use the prompt score as a text-quality estimate only.
5. Present sections: **Prompt final**, **Configuração**, **Por que assim**, **Avaliação**, **Limites/não verificados**, **Adaptações**. Use only relevant headings; keep the copyable artifact obvious.
6. If the requested work is evaluation-only or diagnosis-only and includes no rewritten final prompt, provide findings without pretending approval was obtained.
