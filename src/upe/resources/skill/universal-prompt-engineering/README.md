# universal-prompt-engineering

Agent Skills bundle for evidence-aware prompt design, diagnosis, adaptation, and evaluation. Read `SKILL.md` first and load only the modules relevant to the current task.

The 14 files in `references/original_dossier/` are preserved in full. Their SHA-256 inventory is in `references/original_dossier/ORIGINALS_SHA256.json`. The [interaction helper](workflows/interaction_integration.md) checks staged approval, model recommendation, artifact identity, delivery formatting and the weighted rubric. The host interprets user language and controls permissions, files and actual presentation. `tests/behavioral_eval_protocol.md` specifies model/host tests that remain pending. No model-inference results or host installation are claimed.

See `INSTALLATION.md`, `references/KNOWLEDGE_INDEX.md`, and `references/COMPATIBILITY_MATRIX.md`.
